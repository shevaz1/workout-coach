# 운동 코치

헬스를 처음 시작하는 사람을 위한 기구(머신) 운동 코칭 앱입니다.
휴대폰 인터넷 창에서 열리고, 한 번 연 뒤에는 인터넷 없이도 열립니다. 가입·서버·광고·결제가 없습니다.

## 쓰는 법 (아이폰)

1. Safari에서 <https://shevaz1.github.io/workout-coach/> 를 엽니다.
2. 아래쪽 **공유 버튼(□↑) → 홈 화면에 추가**를 누릅니다.
3. **홈 화면에 생긴 아이콘으로 열어서** 처음 질문(성별·나이·키·몸무게·목표·요일·시간·아픈 부위)에 답합니다. 나이 14~90세, 키 120~220cm, 몸무게 30~200kg 안에서 적어야 하고, 벗어나면 어느 칸인지 빨갛게 표시하고 맞는 범위를 알려 줍니다.
   - Safari 창과 홈 화면 앱은 기록을 따로 보관합니다. Safari에서 먼저 쓰기 시작했다면 `설정 → 기록 파일로 내보내기`로 옮기세요.
4. 다음부터는 아이콘을 누르면 바로 "오늘 할 운동"과 시작 버튼이 보입니다.

## 컴퓨터에서 미리 열어 보기

폴더 안의 `index.html`을 더블클릭하면 바로 열립니다(설치·빌드 없음).
"인터넷 없이 열리기"까지 확인하려면 주소로 열어야 하므로 이 폴더에서 아래를 실행하고 <http://localhost:8000> 을 엽니다.

```
python3 -m http.server 8000
```

## 들어 있는 것

- **오늘**: 오늘 할 운동(온몸 A/B 번갈아), 종목별 무게(kg), 쉬는 날 안내. 며칠 빠져도 다음 차례부터 이어갑니다.
  - 고른 시간(30·45·60분) 안에 끝나도록 종목 수(4~6가지)·세트 수(2~3세트)·쉬는 시간(60~90초)을 맞춥니다. 예: 30분 → 4가지 × 2세트, 45분 → 5가지 × 3세트.
- **운동 중**: 한 번에 한 종목. 시작 자세·끝 자세 그림, 기구 맞추기, 하는 법 3줄, 흔한 실수 1가지. "세트 끝"을 누르면 쉬는 시간이 자동으로 세어집니다. 기구가 차 있으면 뒤로 미룰 수 있습니다. 세로가 짧은 화면(아이폰 SE 등)에서는 무게·횟수 −/＋ 칸이 그림보다 위에 나와 아래 "세트 끝" 버튼에 가리지 않습니다.
  - "오늘 운동 끝내기"를 누르지 않고 닫았다면: 같은 날 다시 열면 하던 곳으로 돌아가고, 다른 날(마지막으로 누른 지 3시간 넘게 지나 날짜가 바뀐 뒤) 열면 그때까지 한 세트를 **시작한 날짜의 기록**으로 저장하고 오늘 할 운동을 보여줍니다. 걸린 시간은 마지막 세트를 누른 때(+15분)까지만 셉니다.
- **무게 정하기**: 처음 하는 기구는 몸무게·성별·나이로 어림한 kg 숫자로 시작하고, 첫 세트 뒤 "가벼웠다/딱 좋다/무거웠다"를 고르면 한 칸 올리거나 내립니다. 그 뒤로는 지난 기록으로 정합니다.
  - 첫 세트 뒤 "가벼웠다/무거웠다"로 무게를 바꿨다면 그 첫 세트는 무게 맞추기용이라 다음 무게를 정할 때 빼고 봅니다. "무거웠다"로 낮춘 무게는 다음번에 한 번 더 같은 무게로 합니다.
  - 모든 세트 12번 성공(그리고 "힘들었다"가 아님) → 한 칸 올림 (다리·등 5kg, 가슴·어깨 2.5kg)
  - 8번을 못 채운 세트가 있음 → 한 칸 내림 / 그 사이 → 같은 무게
  - 3주 넘게 쉬었음 → 한 칸 내려 다시 시작
- **변화**: 주별 운동 횟수, 운동별 무게, 몸무게 그림표. 몸무게는 30~200kg만 기록되고, 벗어나면 저장하지 않았다고 알려 줍니다.
- **식사**: 하루 열량·단백질 목표 숫자와 그 숫자를 채우는(단백질 합계가 목표에 가장 가깝고 모자라지 않게 고른) 하루 식단 예시, 목표별 먹는 요령.
- **설정**: 내 정보 바꾸기, 밝은/어두운 화면, 알림 소리, 기록 내보내기·불러오기(이 앱 형식이 아닌 파일은 거절하고 지금 기록을 그대로 둠), 모든 기구 그림 모음.

## 알아 둘 점

- 종목은 머신 12가지뿐입니다(덤벨·바벨 같은 프리웨이트 없음). 아픈 부위는 무릎·허리·어깨 세 가지만 고를 수 있습니다.
- 시작 무게와 열량은 **어림값**입니다. 헬스장 기구마다 같은 숫자라도 무겁기가 다르므로 첫 세트 뒤 조절이 꼭 필요합니다.
- 자세 그림은 앱이 직접 그리는 단순한 막대 사람 그림입니다. 사진·영상은 없습니다.
- 아이폰은 진동을 지원하지 않아 쉬는 시간 끝은 **소리로만** 알립니다. 옆면 무음 스위치가 켜져 있거나 화면이 꺼져 있으면 소리가 나지 않습니다(운동 중에는 화면이 꺼지지 않게 해 둡니다).
- 기록은 그 휴대폰 안에만 있습니다. 휴대폰을 바꾸거나 Safari 방문 기록·웹사이트 데이터를 지우기 전에 내보내 두세요.
- 일반적인 운동 안내이며 진료를 대신하지 않습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 틀과 모양 |
| `data.js` | 종목, 자세 그림 좌표, 문구 |
| `logic.js` | 시작 무게·다음 무게·종목 교체·식사 계산 규칙 |
| `app.js` | 화면, 저장, 쉬는 시간 |
| `sw.js` | 인터넷 없이 열리게 하는 부분 |
| `manifest.webmanifest`, `icons/` | 홈 화면 아이콘 |

파일을 고쳐서 다시 올릴 때는 `sw.js` 맨 위의 `workout-coach-v3`를 `v4`처럼 바꿔야 휴대폰에 새 파일이 내려갑니다.

## 확인한 것

컴퓨터의 Chrome으로 처음 질문 → 운동 시작 → 세트 기록 → 끝내기 → 다음 무게 변경까지 자동으로 눌러 확인했고, 한 번 연 뒤 인터넷을 끊고 다시 열리는 것도 확인했습니다. 실제 아이폰 Safari에서는 열어 보지 못했습니다.
